# How to run the analysis
1. Navigate to the `scripts/` directory.
2. Run the shell script: `./run_analysis.sh`
# Main Git Commands Used
- `git init`: To start the repository.
- `git add .`: To stage all changed files.
- `git commit -m "message"`: To save a snapshot of the project.
- `git checkout -b <branch>`: To create a new feature branch.
- `git log --oneline`: To view the commit history.
